Free My Vela

Grab the Bluetooth keys to a Vela e-bike you own, so it keeps working now that Vela is gone. Not affiliated with Vela.

Your login and keys never leave your browser. This page talks only to Google/Apple sign-in and Vela's own Firebase database, exactly as the app did. Nothing is sent anywhere else.

Running this: for Apple/Google sign-in, open this file from localhost (Firebase only allows those sign-ins from localhost or Vela's own domain). In this folder run:
python3 -m http.server 8000
then open http://localhost:8000/free-my-vela.html. Email/password works from anywhere. If Apple/Google sign-in shows unauthorized-domain, you're not on localhost.
